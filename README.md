# BMW Sales Dashboard

## Overview

This Power BI project analyzes BMW sales performance across regions, vehicle models, fuel types, and years. The dashboard helps identify sales trends, revenue distribution, EV adoption, and regional performance.

## Tools Used

* Power BI
* DAX
* Data Modeling
* Data Visualization

## Key Metrics

* Total Sales Volume: 43M+
* Total Revenue: $639M+
* EV Share: 50.67%
* Regional Sales Analysis
* Model-wise Performance
* Fuel Type Distribution

## Key Insights

* EV and Hybrid vehicles contribute significantly to overall sales.
* Asia is one of the strongest performing regions.
* 7 Series is among the top-performing BMW models.
* Sales trends remain relatively stable across multiple years.
